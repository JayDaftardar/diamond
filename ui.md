Diamond Hospital UI Color Scheme
Primary Brand Blue (#5D9CEC): The core brand color. Use for primary navigation, main buttons, and prominent UI icons.
Deep Navy (#1E3A8A): High-contrast accent color. Use for primary text, main headings (H1, H2), and footer backgrounds to ensure readability.
Emergency Red (#DC2626): Urgent action color. Use exclusively for "Emergency 24/7" banners, urgent contact buttons, error states, and critical alerts.
Cyan Highlight (#00B4D8): Energetic secondary color. Use for hover states, secondary buttons (like "Learn More"), and subtle gradients.
Clinical White (#FFFFFF): The primary background color. Use to maintain a clean, sterile, and spacious medical feel.
Soft Gray (#F3F4F6): Secondary background color. Use for separating distinct sections, background cards for doctor profiles, or alternating rows.
Design Instructions for Claude: "Please use this color palette to generate the UI code. Ensure the Deep Navy is used for typography against the Clinical White background for accessibility. Use the Primary Brand Blue for standard interactive elements, but strictly reserve the Emergency Red for emergency contacts and critical alerts."
